# Zilla Slab font files

This site's typography uses **Zilla Slab**, licensed under the SIL Open Font License
(see `OFL.txt` in this folder). The `.ttf` files here are self-hosted and referenced
directly by `css/style.css` via `@font-face`.

Files used:
- `ZillaSlab-Regular.ttf` (400)
- `ZillaSlab-Italic.ttf` (400 italic)
- `ZillaSlab-Medium.ttf` (500)
- `ZillaSlab-SemiBold.ttf` (600)
- `ZillaSlab-Bold.ttf` (700)
- `ZillaSlab-BoldItalic.ttf` (700 italic)

If a browser can't load these for any reason, the site falls back to Georgia/serif.
